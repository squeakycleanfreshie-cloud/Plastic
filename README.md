# Plastic
A visual novel game where you work as a plastic surgeon, working in a luxury studio, but it actually has a dark secrect when you start working, and everything seems off.

## Features
- Variables that map personality based on choices
- Branching Story
- Interactive Choices
- Cool Pinterest Art

I made this project utilizing Renpy, and I wrote all my code in Visual Studio Code. I also tested my code utilizing the Renpy Launcher, and I used hackatime to track my time
